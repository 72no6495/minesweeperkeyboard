# 💣 マインスイーパーIME

**マスを開くと文字が入力される、マインスイーパーなキーボード。**

キーボード全体がクラシックなマインスイーパーの盤面になっている Android 用キーボードアプリです。
安全なマスを開くたびに好きな文字が入力され、地雷を踏むとその結果がそのまま文章に書き込まれます。

```
ｗｗｗｗｗｗｗｗｗｗｗｗ3ｗｗ2💥 ゲームオーバー！(41マス開けた)
```

> ジョークアプリですが、空白・削除・改行キーもあるので一応ちゃんと文字は打てます。

[📥 最新版をダウンロード（Releases）](../../releases/latest)

---

## 特徴

- **3 つのモード**（キーボード左下の 💣／⌨ キーで切り替え）
  - 💣 **クラシック盤面**：マスを開くと文字が入力される本来のモード
  - ⌨💣 **QWERTY 盤面でマインスイーパー**：盤面が QWERTY 配列。安全なキーを開くとそのキーの文字が入力され、開いたキーは普通のキーとして何度でも打てます
  - ⌨ **普通のキーボード**：普通に文字を打てるキーボード。押したキーの下で、マインスイーパーが裏でうっすら進みます
- **英語入力とローマ字入力**（QWERTY 系のモード）
  「あ／A」キーで切り替え。ローマ字はひらがなに変換されます（`kitte` → きって、`nn` → ん）。
- **日本語の予測変換**
  約 75 万語の日本語辞書（Mozc のオープンソース辞書）を内蔵。ローマ字で「でんしゃ」と打つと「電車」「電車通勤」…のように候補がニコちゃんの左右に出ます。候補は左右にスワイプしてスクロールできます。
  「わたしはがくせいです」→「私は学生です」のような文の変換、打ちかけのローマ字（`kanj` → かんじ・かんじゃ…）からの予測、確定した単語の次に来そうな言葉（を・に・です…と、よく続けて使う単語）の表示、選んだ候補の学習にも対応。自分で登録した単語（ユーザー辞書）も使えます。
- **マスを開く ＝ 文字入力**
  安全なマスを開くと、設定した文字（初期値「ｗ」）が入力されます。空白マスが連鎖して 30 マス開けば「ｗ」が 30 個並びます。
- **入力する文字は 4 種類から選べる**
  - 決まった文字（「ｗ」「草」など）
  - 座標に応じた文字：マスごとに五十音などの文字が割り当てられ、開いた場所の文字が入力されます。閉じたマスに文字が表示されるので、狙って打つこともできます
  - 座標そのもの：`B3` のように、開いたマスの位置が入力されます
  - ランダムな文字：開くたびに候補の中からランダムに入力されます
- **数字マスをタップすると数字が入力される**
  開いている数字マスをタップすると、その数字（1〜8）が入力されます。周りの旗の数が合っていれば、周囲のマスもまとめて開きます。
- **結果も自動で入力**
  - 地雷を踏むと `💥 ゲームオーバー！(15マス開けた)`
  - クリアすると `🎉 マインスイーパー クリア！ タイム: 45秒`
- **懐かしい Windows 95/98 風の見た目**
  出っ張ったグレーのマス、色付きの数字（1=青、2=緑、3=赤、4=紺…）、赤い LED のカウンター、表情が変わるニコちゃん。
- **盤面サイズを選べる**
  初級（9×9・地雷10）、中級（16×16・地雷40）、上級（16×30・地雷99）、カスタム（5〜30 マス）。キーボード上のボタンでいつでも切り替えられます。
- **最初の一手は必ず安全**
  1 マス目とその周囲には地雷が置かれません。
- **インターネット権限なし**
  通信は一切しません。入力した内容を外部に送ることもありません（使う権限は振動のみです）。

## 動作環境

- Android 7.0 以上

## インストール

1. [Releases](../../releases/latest) から `minesweeper-ime-vX.Y.Z.apk` をダウンロードします。
2. ダウンロードした APK を開いてインストールします。
   「提供元不明のアプリ」の確認が出たら、ブラウザやファイルアプリからのインストールを許可してください。
3. ホーム画面の **マインスイーパーIME** を開きます。
4. **「キーボードを有効にする」** を押し、システム設定で **マインスイーパーキーボード** を ON にします。
   （キーボードアプリを有効にするときは、Android から「入力した文字を収集できる可能性があります」という定型の警告が表示されます。このアプリは通信を行いません。）
5. **「入力方法をマインスイーパーに切り替える」** を押して選択します。
6. 設定画面の一番下の「試し打ち」欄をタップすると、すぐに遊べます。

普段使っているキーボードに戻すときは、キーボード下段の 🌐 ボタンを押します（長押しで一覧から選べます）。

## 遊び方

### 盤面の操作

| 操作 | 動き | 入力される文字 |
| --- | --- | --- |
| 閉じたマスをタップ | マスを開く | 開いたマスごとに 1 文字（決まった文字／座標の文字／座標／ランダム） |
| 開いている数字マスをタップ | 周りの旗の数が合っていれば周囲を一括オープン | その数字（＋開いたマスの分の文字） |
| 長押し | 旗を立てる／外す | なし |
| 地雷を踏む | ゲームオーバー | `💥 ゲームオーバー！(Nマス開けた)` |
| すべての安全なマスを開く | クリア | `🎉 マインスイーパー クリア！ タイム: N秒` |

ゲーム終了後は、盤面をタップすると新しいゲームが始まります（ニコちゃんでもリセットできますが、1 文字消えます）。

### QWERTY 盤面でマインスイーパー（⌨💣）

```
 1 2 3 4 5 6 7 8 9 0
 q w e r t y u i o p
 a s d f g h j k l ー
 z x c v b n m 、。？
```

| 操作 | 動き |
| --- | --- |
| 閉じたキーをタップ | キーを開いて、そのキーの文字を入力。地雷なら `💥 ゲームオーバー！` |
| 開いたキーをタップ | そのキーの文字を入力（数字は右上に小さく表示） |
| 閉じたキーを長押し | 旗を立てる／外す |
| 開いたキーを長押し | 周りの旗の数が合っていれば周囲を一括オープン |

### 普通のキーボード（⌨）

どのキーも普通に入力できます。押したキーの下のマスが裏で開き、数字や旗、地雷がうっすら表示されます。
地雷を踏むと 1.5 秒後に裏のゲームが新しくなります。

- **🚩キー**（Z の左）：押してから次のキーを押すと、そのキーの下に旗を立てます（もう一度で外す）。🚩キーを長押しすると、解除するまで旗を立て続けるモードになります
- 最後に立てた旗は、ゲームが終わっても **3 つまで残ります**。残った旗の位置には、次のゲームで地雷が置かれません
- キーを長押しすると記号・数字を入力します（拡大表示にその記号が出ます）。設定で「旗を立てる」「なし」にも変えられます

### 文字入力と予測変換（QWERTY 系）

| キー | 動き |
| --- | --- |
| あ／A | ローマ字入力と英語入力を切り替え |
| ⇧ | 英語入力で次の 1 文字を大文字にする。長押しでキャプスロック（⇪） |
| 記号 | 押すたびに 記号・数字 → 絵文字 → 文字 の順に切り替え |
| 候補（ニコちゃんの左右） | タップでその単語を入力。左右にスワイプでスクロール |
| ニコちゃん | タップで 1 文字削除して盤面をリセット、長押しで入力欄の文字をすべて削除して盤面をリセット（すべてのモード共通。普通のキーボードでは最近の旗を 3 つまで残す） |
| 空白 | 入力中なら次の候補を選ぶ（選んだ候補が入力欄に表示される）。入力中でなければスペース |
| ⏎ | 選んでいる候補、または入力中の文字をそのまま確定（入力中でなければ改行） |
| ⌫ | 入力中の文字を 1 文字消す |

### 画面の見方

```
┌──────────────────────────────┐
│ [010]        (🙂)       [045] │  残り地雷数 ／ ニコちゃん（タップで 1 文字削除＋リセット）／ 経過時間
├──────────────────────────────┤
│                              │
│            盤 面              │
│                              │
├──────────────────────────────┤
│[💣][初級][🚩][📋][⚙][🌐][空白][⌫][⏎]│
└──────────────────────────────┘
```

| ボタン | 機能 |
| --- | --- |
| 💣／⌨💣／⌨ | モードを切り替え（設定で有効にしたモードだけ） |
| 初級／中級／上級／カスタム | クラシック盤面のサイズを切り替え（新しいゲームになります）。QWERTY 系では「あ／A」キー |
| 🚩 | 旗モード。ON の間はタップで旗、長押しでマスを開く。QWERTY 系では「⇧」キー |
| 📋 | クリップボード（下の「クリップボード」を参照） |
| ⚙ | 設定画面を開く |
| 🌐 | 次のキーボードに切り替え（長押しで一覧） |
| 空白／⌫／⏎ | スペース・削除（長押しで連続削除）・改行／送信 |

### クリップボード（📋）

📋キーを押すと、盤面の代わりにクリップボードのパネルが開きます（もう一度押すと盤面に戻る）。

- 上の段：**コピー**・**切り取り**・**全選択**・**貼り付け**（入力欄の文字に対して）、**履歴消去**（ピン留め以外を消す）
- 履歴：コピーした文字が新しい順に並びます。**タップで貼り付け**、**📌でピン留め**（一番上に固定され、自動では消えない）、**🗑で削除**
- 履歴はピン留め以外で最大 30 件まで端末内に保存します。パスワードなど、アプリが「機密」と指定した文字は残しません（Android 13 以降）

## 設定

ホーム画面のアイコン、またはキーボードの ⚙ ボタンから開けます。

| 項目 | 内容 |
| --- | --- |
| キーボードのモード | 今のモードと、モード切替キーで切り替えるモード（それぞれオン／オフ） |
| 使う入力 | ローマ字入力・英語入力のオン／オフと、最初に使う入力 |
| QWERTY 盤面の地雷の数 | QWERTY 盤面でプレイするときの地雷の数（1〜20、初期値 6） |
| 裏のマインスイーパー | 普通のキーボードモードで裏のゲームを動かすか、地雷の数、結果（💥／🎉）も入力するか |
| テーマ | クラシック（グレー）／ダーク／ティール／ヴェイパーウェイブ（薄紫×ピンク） |
| キー配列 | QWERTY／QWERTZ／AZERTY と、数字の行の表示 |
| キーの高さ・文字の大きさ | QWERTY 盤面と普通のキーボードのキーの高さ（36〜72dp）と文字の大きさ（70〜150%） |
| キーの拡大表示・キー音・🌐キー | 押したキーを上に大きく表示するか、キー音を鳴らすか、🌐キーを表示するか |
| 長押し | 長押しと判定するまでの時間（200〜1000ms）と、普通のキーボードで長押ししたときの動作（記号・数字／裏のゲームに旗／なし） |
| 英語入力 | 文の始めの自動大文字、スペース 2 回でピリオド、候補を選んだ後のスペース |
| 句読点 | 日本語入力の句読点（、。／，．／，。） |
| 学習 | 選んだ候補を覚えて次から先に出すか。学習した内容の消去 |
| クリップボード | コピーした文字を履歴に残すか。履歴の全消去（ピン留めも含む） |
| 予測変換 | 予測変換のオン／オフ |
| 日本語辞書 | ローマ字入力で日本語辞書（Mozc）の単語も候補に出すか。ライセンスの表示もここから |
| ユーザー辞書 | 1 行に 1 つ「よみ,単語」で登録（よみを省略すると単語そのものがよみ）。候補の先頭に出ます |
| 入力する文字の決め方 | 「決まった文字」「座標に応じた文字」「座標そのもの（例：B3）」「ランダムな文字」から選択 |
| 入力する文字 | 「決まった文字」のときに入力される文字。「ｗ」「草」「あ」「💣」など何でも OK（複数文字も可） |
| 文字表 | 「座標に応じた文字」のとき、盤面の左上から右へ 1 マスずつ割り当てる文字。足りなければ最初に戻ります。プリセット：五十音・ABC・数字・絵文字 |
| ランダムの候補 | 「ランダムな文字」のときに選ばれる文字。プリセット：ひらがな・カタカナ・英数字・絵文字 |
| 閉じたマスに文字を表示 | 座標系のモードで、開くと入力される文字を閉じたマスに薄く表示 |
| 連鎖オープン時の入力 | 「開いたマスの数だけ連続入力」または「1 回のタップにつき 1 回だけ」 |
| 最大文字数 | 1 回の連鎖で入力する文字数の上限（0 は無制限） |
| 一括オープン | 数字マスのタップで周囲をまとめて開くかどうか |
| 振動フィードバック | 長押しや爆発時に振動するかどうか |
| 盤面サイズ | 初級／中級／上級／カスタム（縦・横・地雷の数） |
| 盤面の最大高さ | 盤面が画面の何％まで使うか。大きい盤面はこの高さに収まるよう縮小されます |

## よくある質問

**Q. 盤面のマスが小さすぎてタップしにくい**
A. 設定の「盤面の最大高さ」を大きくするか、初級など小さめの盤面にしてください。

**Q. アップデートしようとしたら「パッケージが既存のパッケージと競合しています」と出る**
A. 現在の APK はビルドごとに署名が異なる場合があります。お手数ですが、一度アンインストールしてから新しいバージョンをインストールしてください。

**Q. 文字表やランダムの候補に単語を入れたい**
A. カンマ（`,` か `、`）で区切ると、`おはよう,こんにちは,おやすみ` のように複数文字を 1 マス分として登録できます。

**Q. 漢字に変換できない**
A. 設定の「日本語辞書（Mozc）の単語も候補に出す」がオンになっているか確認してください。初めて使うときは辞書の展開（約 60 MB）に数秒かかり、その間は候補が出ません。辞書にない言葉は「よみ,単語」でユーザー辞書に登録できます。
なお、文節に区切って変換する機能はないので、長い文は単語ごとに候補から選んでください。

**Q. アプリの容量が大きい**
A. 日本語辞書のためです。APK は約 18 MB で、初回に端末内へ約 60 MB の辞書を展開します。

**Q. 速く打つと文字が抜ける**
A. 普通のキーボードと QWERTY 盤面は、前のキーから指を離す前に次のキーに触れても、前のキーをその場で入力するようにしています。それでも抜ける場合は、設定の「長押しと判定するまでの時間」を長くするか、長押しの動作を「なし」にしてください。

**Q. パスワード欄でも使える？**
A. 使えますが、地雷を踏むとパスワードに `💥 ゲームオーバー！…` が書き込まれるのでおすすめしません。

## ソースからビルドする

JDK 17 と Android SDK（API 35）が必要です。Android Studio でこのフォルダを開くか、次のコマンドを実行します。

```bash
./gradlew testDebugUnitTest   # ゲームロジックの単体テスト
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk が生成されます
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

adb で有効化と切り替えをまとめて行う場合：

```bash
adb shell ime enable com.minesweeperkeyboard.ime/.MinesweeperIME
adb shell ime set    com.minesweeperkeyboard.ime/.MinesweeperIME
```

### プロジェクト構成

```
app/src/main/java/com/minesweeperkeyboard/ime/
├── MinesweeperEngine.kt       ゲームロジック（Android 非依存）
├── TextGimmick.kt             開いたマスの数 → 入力する文字列 の変換
├── QwertyInput.kt             モード・QWERTY 配列・入力の組み立て・予測変換の辞書
├── RomajiConverter.kt         ローマ字 → ひらがな変換
├── LearningModel.kt           予測変換の学習
├── MinesweeperIME.kt          キーボード本体（InputMethodService）
├── MinesweeperBoardView.kt    盤面の描画とタップ／長押しの判定
├── ClassicViews.kt            LED カウンター・ニコちゃん・クラシックなボタン
├── ClassicStyle.kt            立体枠・地雷・旗などの描画
├── ImePrefs.kt                設定の保存
├── JapaneseDictionary.kt      日本語辞書の検索（ファイルを読み込まずに二分探索）
├── SystemDictionaryLoader.kt  日本語辞書の展開と読み込み
└── SettingsActivity.kt        設定画面
tools/build_ja_dictionary.py   Mozc の辞書から日本語辞書ファイルを作るスクリプト
```

日本語辞書はリポジトリに含めていません。ビルド前に次のコマンドで作成してください（GitHub Actions では自動で実行されます）。作らずにビルドした場合は、ユーザー辞書だけで動きます。

```bash
python3 tools/build_ja_dictionary.py   # app/src/main/assets/ に辞書を作成
```

## クレジット

予測変換の日本語辞書は [Mozc](https://github.com/google/mozc) のオープンソース辞書（`src/data/dictionary_oss`）を加工したものです。IPAdic、ICOT Free Software、沖縄辞書などのライセンスに従って配布しています。ライセンスの全文はアプリの設定画面「日本語辞書のライセンスを表示」から確認できます。
